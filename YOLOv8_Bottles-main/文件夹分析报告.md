# YOLOv8_Bottles 项目分析报告

## 一、项目概述

这是一个基于 **YOLOv8** 的目标检测项目，用于在工业生产线上对塑料瓶进行分类检测。项目由俄罗斯开发者创建，属于学术研究项目（НИР - 科学研究工作）。

### 项目目标
- **主要任务**：在生产传送带上对塑料瓶进行实时分类检测
- **检测类别**：
  1. **透明瓶**（透明瓶）
  2. **有色瓶**（有色瓶）
  3. **垃圾**（垃圾/杂物）

### 项目成果
- 已发表学术论文：https://www.elibrary.ru/item.asp?id=67054708
- 模型在测试集上取得了较高的检测精度

## 三、模型配置详情

### 基础模型
- **架构**：YOLOv8n（Nano版，最轻量级）
- **参数量**：3,011,433 参数
- **计算量**：8.2 GFLOPs
- **层数**：225层（融合后168层）

### 训练参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 任务类型 | detect | 目标检测 |
| 训练轮数 | 200 | 最大训练epoch |
| 实际训练 | 104 | 早停触发 |
| 批次大小 | 16 | batch size |
| 图像尺寸 | 640x640 | 输入分辨率 |
| 早停耐心 | 50 | patience值 |
| 优化器 | SGD | 自动选择 |
| 初始学习率 | 0.01 | lr0 |
| 动量 | 0.9 | momentum |
| 权重衰减 | 0.0005 | weight_decay |
| 预热轮数 | 3 | warmup_epochs |
| 数据增强 | randaugment | 自动增强 |
| 工作线程 | 8 | dataloader workers |
| 预训练 | True | 使用COCO预训练权重 |

### 数据增强配置
- **HSV色调调整**：0.015
- **HSV饱和度**：0.7
- **HSV亮度**：0.4
- **平移**：0.1
- **缩放**：0.5
- **水平翻转**：0.5
- **Mosaic增强**：1.0
- **随机擦除**：0.4

## 四、训练结果分析

### 训练过程
- **训练时间**：约5.05小时
- **GPU使用**：NVIDIA GeForce GTX 1650 Ti (4GB)
- **训练集**：7,002张图像
- **验证集**：300张图像，672个实例
- **早停触发**：第104轮（第54轮后50轮无改善）

### 最终验证指标（最佳模型 - 第54轮）

| 指标 | 值 |
|------|-----|
| **Precision（精确率）** | 0.772 |
| **Recall（召回率）** | 0.780 |
| **mAP@50** | 0.850 |
| **mAP@50-95** | 0.636 |

### 各类别详细指标

| 类别 | 图像数 | 实例数 | Precision | Recall | mAP@50 | mAP@50-95 |
|------|--------|--------|-----------|--------|--------|-----------|
| **透明瓶（透明瓶）** | 300 | 396 | 0.945 | 0.741 | 0.931 | 0.701 |
| **有色瓶（有色瓶）** | 300 | 48 | 0.585 | 0.854 | 0.798 | 0.693 |
| **垃圾（垃圾）** | 300 | 228 | 0.787 | 0.746 | 0.822 | 0.514 |
| **总体** | 300 | 672 | 0.772 | 0.780 | 0.850 | 0.636 |

### 推理速度
- **预处理**：0.2ms/图像
- **推理**：4.5ms/图像
- **后处理**：0.8ms/图像
- **总计**：约5.5ms/图像

## 五、各类别表现分析

### 1. 透明瓶（透明瓶）- 表现最佳
- **Precision**: 0.945（非常高）
- **Recall**: 0.741
- **mAP@50**: 0.931
- **分析**：该类样本最多（396个），模型学习充分，误检率低

### 2. 有色瓶（有色瓶）- 样本较少
- **Precision**: 0.585（较低）
- **Recall**: 0.854（较高）
- **mAP@50**: 0.798
- **分析**：样本量最少（仅48个），导致精确率偏低，但召回率较高，说明漏检少但误检多

### 3. 垃圾（垃圾）- 中等表现
- **Precision**: 0.787
- **Recall**: 0.746
- **mAP@50**: 0.822
- **mAP@50-95**: 0.514（较低）
- **分析**：定位精度相对较低，边界框回归不够准确

## 七、项目特点与总结

### 优点
1. **轻量级模型**：使用YOLOv8n，适合边缘设备部署
2. **推理速度快**：单张图像约5.5ms，满足实时检测需求
3. **整体mAP较高**：mAP@50达到0.85
4. **透明瓶检测精度高**：mAP@50达0.931

### 不足与改进建议
1. **有色瓶样本不足**：仅48个实例，建议增加样本量
2. **mAP@50-95偏低**：总体0.636，说明边界框定位精度有提升空间
3. **训练触发早停**：104轮即停止，可考虑调整学习率策略继续训练
4. **有色瓶精确率偏低**：0.585，容易误检

### 适用场景
- 工业生产线上的塑料瓶自动分类
- 回收站的瓶类自动分拣
- 需要实时检测的轻量级应用场景

## 八、使用说明

### 环境要求
- Python 3.8+
- PyTorch 2.2.1+
- ultralytics 8.1.19+
- CUDA支持（推荐）

### 快速开始
```python
from ultralytics import YOLO

# 加载训练好的模型
model = YOLO('model/weights/best.pt')

# 进行预测
results = model('path/to/image.jpg')
```
