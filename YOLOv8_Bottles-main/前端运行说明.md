# YOLOv8 瓶子检测前端运行说明

## 功能

这个前端可以完成：

- 上传瓶子图片
- 调用本地 `model/weights/best.pt` 模型检测
- 显示检测后的图片
- 显示检测到的类别、置信度和目标数量

## 目录说明

```text
YOLOv8_Bottles-main/
├── app.py                 # Flask 后端入口
├── requirements.txt       # 依赖列表
├── templates/
│   └── index.html         # 前端页面
├── static/
│   ├── style.css          # 页面样式
│   └── app.js             # 前端交互逻辑
├── uploads/               # 上传图片保存目录
├── outputs/               # 检测结果图保存目录
└── model/weights/best.pt  # YOLOv8 模型
```

## 在 VS Code 中运行

### 1. 打开项目文件夹

用 VS Code 打开 `YOLOv8_Bottles-main` 文件夹。

### 2. 激活虚拟环境

如果已经有 `.venv`，在 VS Code 终端运行：

```powershell
.venv\Scripts\activate
```

如果没有虚拟环境，可以先创建：

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### 3. 安装依赖

```powershell
pip install -r requirements.txt
```

如果安装 PyTorch 很慢，可以先尝试：

```powershell
pip install ultralytics flask opencv-python
```

### 4. 启动服务

```powershell
python app.py
```

启动成功后，浏览器打开：

```text
http://127.0.0.1:5000
```

## 常见问题

### 1. 报错：No module named ultralytics

说明依赖没有安装，运行：

```powershell
pip install ultralytics
```

### 2. 报错：No module named flask

运行：

```powershell
pip install flask
```

### 3. 报错：模型文件不存在

确认模型文件是否在：

```text
model/weights/best.pt
```

### 4. 检测速度慢

如果电脑没有 GPU，模型会使用 CPU 推理，速度会慢一些。这个项目使用的是 YOLOv8n，已经是较轻量的模型。
